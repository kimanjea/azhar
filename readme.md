# Azhar Amir Kimanje · Portfolio

Static site served by GitHub Pages at https://kimanjea.github.io/azhar/. No build step.

| Path | What it is |
|---|---|
| `index.html` | Home: positioning, shipped apps, current roles, research, publications, recognition |
| `research.html` | R&D projects, publications, research interests, organizations |
| `work.html` | Shipped apps (App Store, Meta Quest Store, Microsoft Store), featured builds, games |
| `experience.html` | Every role grouped by organization, leadership, entrepreneurship, volunteering |
| `recognition.html` | Awards, grants, scholarships, certificates |
| `about.html` | Story, education, skills, languages |
| `styles/site.css` | Design tokens and all styles (light and dark follow the system setting) |
| `scripts/site.js` | Nav, mobile menu, copy email, scroll reveals. Pages work without it. |
| `img/` | Optimized images (`work/` screenshots, `logos/`, `portrait.jpg`, `og.jpg` share image) |
| `Azhar-Amir-Kimanje-CV.pdf` | CV linked from every page |
| `_legacy/` | The previous Bootstrap site and full-size original images. Not published (GitHub Pages skips `_` folders). |

The navigation and contact footer are repeated in every page. When you add a page or change a nav link, update all six files.
